# 화면·사용 흐름 명세

## 모바일 탐색

하단 메뉴: 오늘 / 기록 / 루틴 / 더보기. 오늘 화면에 ‘운동 시작’과 ‘텍스트로 기록’을 주요 동작으로 배치합니다. 주요 입력은 키보드 숫자 패드와 큰 터치 영역을 사용합니다.

| 화면 | 주요 내용 | 완료 조건 |
|---|---|---|
| 로그인·초대 가입 | 초대 확인, 계정 생성, 로그인·로그아웃 | 만료·사용된 초대 구분, 초대 없는 가입 차단 |
| 오늘 | 예정 루틴, 진행 중 세션, 최근 수행, 운동 시작 | 휴식일·기록 없음·진행 중을 구분 |
| 운동 기록 | 종목 카드, 이전 기록, 세트별 중량·반복, 마지막 RIR, 종목 추가 | 저장 상태·실패·재시도를 표시하고 운동 종료 가능 |
| 텍스트 기록 | 원문 입력, 해석된 종목·세트 표, 불명확 항목 수정 | 확정 전 DB 실적에 반영하지 않고 확인 후 저장 |
| 기록 목록·상세 | 달력·목록, 날짜·종목 필터, 상세 수정·삭제 | 본인 기록만 표시하고 테스트는 기본 제외 |
| 종목별 추이 | 지난 중량·반복·RIR, 같은 장비·방식의 비교 | 중량만으로 향상 판단하지 않고 누락 RIR 구분 |
| 루틴 | 요일·운동 순서·목표 세트·반복·RIR 편집 | 수정한 루틴은 다음 운동부터 적용 |
| 종목 | 공용 검색, 개인 추가·별칭·장비 설정 | 공용 종목을 일반 사용자가 변경할 수 없음 |
| Notion 가져오기 | 연결·대상 선택, 매핑·미리보기, 결과·충돌 | 재가져오기와 실패 재시도 가능 |
| 설정·운영 | 시간대·단위, AI 사용량, 연결 해제 / 관리자 초대·상태 | 관리자도 일반 화면에서 타인의 운동 원문을 열람하지 않음 |

## 운동 기록 화면 초안

```text
오늘의 운동                 저장됨
RDL · 덤벨 2개
지난 기록: 19kg · 15/15/15 · 마지막 RIR 2

세트   개당 kg   반복   완료
 1      19      15     ✓
 2      19      15     ✓
 3      19      15     ✓
[+ 세트 추가]
마지막 세트 RIR  [ 2 ]
[세트별 RIR 보기]   [메모]

[종목 추가]            [운동 종료]
```

값이 입력돼 있어도 세트 수행 완료로 자동 간주하지 않습니다. 이전 값 복사는 입력을 돕는 초안이며 실제 수행 여부는 별도로 확인합니다. 건너뛴 세트는 실제 볼륨·마지막 세트 계산에서 제외합니다.

## 자연어 기록 흐름

1. `RDL 19kgx2 15 15 15 RIR 2` 입력.
2. 파서가 날짜·종목·세트·RIR 초안을 생성. 명확한 형식은 규칙 파서 우선, 자유 문장은 AI 보조.
3. 화면에 ‘RDL / 덤벨 2개 / 19kg / 15·15·15 / 마지막 RIR 2’를 표시.
4. 날짜가 없으면 사용자 시간대의 오늘을 초안으로 표시. 복수 종목 중 RIR 적용 대상이 불명확하면 선택 요구.
5. 같은 날짜·종목 기록이 있으면 중복 후보를 보여주고 추가·정정·별도 세션을 선택.
6. 사용자가 확인하면 트랜잭션으로 저장. 저장 응답 확인 후 ‘저장됨’ 표시.

AI 오류·한도 초과 시 원문과 초안을 유지하고 직접 입력으로 계속 진행할 수 있습니다.

## 저장·수정·공유

- 편집 중 값은 기기 내 초안에 보관하되 저장 완료와 구분. 계정별 키를 사용하고 로그아웃 시 제거.
- 서버 저장에는 요청 ID를 사용해 재시도 중복 방지. 동시 편집 충돌은 재조회·병합 대상으로 표시.
- 취소된 초안·오류 응답은 운동 실적에 포함하지 않음.
- 루틴 공유는 후속 기능으로, 원본 링크를 통한 복사 방식부터 검토. 개인 운동일지 공개는 별도 명시적 설정 없이 허용하지 않음.

## 대표 인수 시나리오

- 19kg 15회 3세트 마지막 RIR 2를 입력하고, 재조회해 3번째 세트에만 RIR이 있는지 확인.
- 두 번째 세트만 20kg으로 변경하면 개별 세트 기록과 계산이 일치.
- 4번째 세트를 추가하면 마지막 RIR이 미입력으로 표시되며 3번째 세트의 RIR 2는 보존.
- 운동을 부분 완료해도 수행한 세트만 남고 미수행 세트는 통계에서 제외.
- 사용자가 다른 사람의 상세 URL을 입력해도 데이터가 노출되지 않음.
- 연결이 끊긴 상태에서는 미저장 상태가 분명하고 복구 후 중복 없이 저장.
