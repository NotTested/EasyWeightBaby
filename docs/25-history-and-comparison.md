# D5 기록 기간 조회·이전 실제 수행 비교

기록 화면에 기간/진행 상태 필터와 20개 단위 탐색을 연결하고, 실제 운동 상세에서 이전 날짜의 완료 본세트를 비교한다. 원본 Notion 적재·마이그레이션·의존성 추가는 없다. C6~D4 작업을 기존 브랜치에서 보존했다.

## 기간별 조회

/history는 시작일·종료일·진행 상태(전체/진행 중/완료)를 GET 폼으로 조회한다. 날짜는 저장된 localDate를 기준으로 양 끝을 포함한다. UTC 날짜로 바꾸지 않는다. 테스트/계획은 항상 제외한다. 조건 초기화, 다음 20개, 첫 페이지를 제공한다.

GET /api/history는 같은 from/to/status/after 조건을 지원한다. 실제 존재하는 ISO 날짜와 시작일≤종료일을 검증하고 알 수 없는 필드·중복 파라미터를 거부한다. 사용자 ID는 인증된 사용자로 결정한다. items/hasMore/nextAfter를 반환하고 Cache-Control=no-store를 사용한다.

정렬은 localDate DESC, createdAt DESC, id DESC다. after는 본인·같은 조건의 실제 기록을 찾아 정렬 기준으로 다음 행을 선택하는 커서다. 단순 offset이 아니며, 동일 날짜/시각에도 ID로 순서를 고정한다. 다른 계정·변경된 조건·삭제된 커서는 400과 처음부터 조회 안내를 준다. SSR 화면은 유효하지 않은 조건을 안내하고 데이터를 표시하지 않는다. 변경 중인 기록 전체를 하나의 DB 스냅샷으로 고정하는 탐색은 아니다.

기존 GET /api/sessions의 100개 제한·기록 구분 조회 계약은 바꾸지 않았다. /history의 예전 ‘최근 100개만’ 설명은 이 문서가 대체한다. 달력·전체 건수·검색어·CSV 내보내기는 이번 범위에 포함하지 않는다.

## 이전 수행 선택 기준

GET /api/sessions/:id/comparison은 본인의 actual 세션만 허용한다. 테스트/계획·타인 세션은 404이며 관리자 예외는 없다. 현재 세션의 저장된 최대 40개 종목을 기준으로 조회한다.

각 종목의 동일 exerciseId에 대해 아래 조건을 만족하는 이전 기록 하나를 선택한다.

- 같은 계정의 actual, 세션 상태 completed.
- 현재 localDate보다 **이전 날짜**. 같은 날짜와 미래 날짜는 제외한다.
- 해당 종목에 수행 완료한 본세트 행이 하나 이상 있음. 미완료·워밍업만 있는 종목은 건너뛴다.
- 가장 최근 날짜를 우선하고, 같은 이전 날짜에는 세션 createdAt/id와 종목 position으로 선택 순서를 고정한다. 이는 기록 생성/행 순서이며 원본에 없는 실제 수행 시각을 추정하지 않는다.

종목 이름만으로 다른 ID를 합치지 않는다. 이름이 바뀐 같은 ID의 과거 스냅샷은 그대로 보여준다. 장비·수행방식·측정방식·벤치 각도 중 하나라도 다르면 수치 비교 주의 안내를 표시한다.

## 표시와 입력 보존

상세의 ‘이전 수행 조회·새로고침’은 현재 저장 기록과 선택된 이전 기록을 PC에서 나란히, 모바일에서 세로로 표시한다. 각 행의 수행/미완료, 본세트/워밍업, 좌우, 덤벨 개당 kg·덤벨 수, 반복, 실제 RIR과 원래 이름/장비/각도를 유지한다. 미입력과 0을 구분하고 좌우 측수를 다시 곱하지 않는다.

마지막 RIR은 마지막 완료 본세트의 값이다. 그 값이 NULL이면 이전의 RIR 0이나 다른 비어 있지 않은 값으로 대체하지 않고 미입력으로 표시한다. 이후 워밍업·미완료 행은 기준을 바꾸지 않는다. 완료 본세트가 없으면 없다고 표시한다.

비교는 서버 저장값을 읽기만 한다. C7의 편집 모델·로컬 초안·완료 상태를 바꾸지 않는다. 저장 후 다시 조회하면 갱신되며, 네트워크/세션 오류는 안내 후 재시도할 수 있다. 비교 화면의 이전 상세 링크로 이동할 때는 기존 미저장 입력 보호가 적용된다. 성장률·볼륨 차이·1RM·다음 중량 추천을 자동 계산하지 않는다. 유산소 비교와 종목별 전체 추이는 이번 범위 밖이다.

API는 필요한 운동 메타데이터와 세트만 반환하며 운동 메모·인증 정보·타인 실적을 포함하지 않는다. 개인 응답은 캐시하지 않는다.

## 검증

합성 데이터로 날짜 경계·커서 중복 방지·잘못된 조건·타인 커서/세션 차단, 테스트/계획/진행 중/같은 날/워밍업/미완료 제외, 종목 ID 유지·좌우 반복·RIR NULL/0·장비 차이 안내를 검증한다. PC/320px 브라우저는 기간 선택·페이지 이동·비교·모바일 폭과 비교 중 입력 초안 보존·저장을 확인한다.

실제 원본은 계속 보류 상태이며 앱에 적재하지 않았다. 다음 E1은 NAS용 Docker 운영 패키징을 작은 단위로 준비한다. 원본 적재는 별도 검토와 대상 계정 선택 후 진행한다.
