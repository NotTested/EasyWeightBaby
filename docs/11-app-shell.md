# B1 모바일·PC 공통 화면

작성일: 2026-10-28 (Asia/Seoul).

## 구현 범위

- AppShell: 공통 헤더·계정 메뉴·본문 건너뛰기·주 메뉴·본문·푸터. 기존 관리자 초대 화면도 같은 구조를 사용한다.
- 주 메뉴: 오늘 `/`, 기록 `/history`, 루틴 `/routines`, 설정 `/settings`. PC에서는 상단, 700px 이하에서는 하단 고정 메뉴를 사용한다. safe-area 하단 여백과 콘텐츠 하단 여백을 둔다.
- 현재 화면을 색상과 aria-current=page로 표시한다. 주 메뉴는 같은 링크를 중복 렌더링하지 않고 CSS로 배치만 바꾼다. 키보드 Tab/Enter와 본문 건너뛰기를 지원한다.
- 새 화면은 서버에서 인증을 확인한다. 로그인하지 않은 상태의 직접 URL 접근은 로그인으로 이동한다. 설정에는 본인 이름·이메일·시간대·역할만 조회한다. 관리자만 초대 관리 링크를 볼 수 있다.
- 오늘의 최근 운동일지는 기존 소유권 필터를 유지한다. 기록 목록·달력·루틴 편집·운동 시작·설정 편집·PWA 설치는 구현하지 않았으며 준비 중임을 표시한다. 샘플 운동 기록을 만들거나 원본 Notion 데이터를 자동으로 가져오지 않았다.

## 검증

`npm run test:browser`에서 Chromium 1280px, 390px, 320px 시나리오와 상위 테스트를 합쳐 총 4개가 통과했다. 기존 초대 발급→가입→로그인→로그아웃 검증에 다음을 추가했다.

- 키보드 Enter로 기록·루틴·설정 화면 이동.
- 각 화면 h1과 주 메뉴의 유일한 현재 위치 표시.
- 세 화면의 가로 넘침 없음, 설정에서 현재 가입자의 이메일 표시.
- 새로고침 후 첫 Tab이 본문 건너뛰기 링크에 도달하고 Enter로 main-content에 포커스 이동.
- 로그아웃 후 새 화면의 직접 접근이 로그인으로 이동.
- 기존 관리자 기능 차단과 브라우저 pageerror 없음.

타입 검사와 운영 빌드를 통과했다. 최종 standalone 운영 테스트도 총 3개 pass, fail/skip 0으로 DB 응답·정적 자원·로그인·로그아웃을 확인했다. 실물 모바일 기기·스크린리더의 모든 동작을 검증한 것은 아니다.
