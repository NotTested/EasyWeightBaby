# C6 유산소·메모·운동 종료

`feat/c6-cardio-notes-completion`에서 구현한다. 기준은 C1~C5 커밋 `42e6451`이다. 이 문서는 C4/C5 문서의 ‘진행 중 운동만 수정’, ‘유산소·종료 미구현’ 설명을 대체한다.

## 기록 항목

- 유산소는 운동일지에 별도 CardioRecord 배열로 저장한다. 종류(1~80자), 시간(분, NULL 또는 0~1440), 선택 거리(km, NULL 또는 0~1000), 자유형 강도/Zone 설명(300자), 메모(1000자), 수행 완료를 구분한다. 소수 시간·거리를 허용한다.
- 완료한 유산소에는 시간이 필요하다. 종류는 미완료 행에도 필요하다. 빈칸은 NULL이고 입력한 0은 실제 0이다. 시간·거리·완료를 서로 추정하지 않는다. 강도와 메모는 원문 줄바꿈을 보존한다.
- 한 운동에 최대 20개 유산소 행을 기록하고 추가·삭제할 수 있다. 완료한 행 삭제는 확인한다. 실제 종목 사전이나 루틴 목표를 유산소 기록으로 자동 변환하지 않는다.
- 운동일지의 실제 메모 `actualNotes`(최대 5000자)는 루틴에서 가져온 목표 메모와 분리한다.

## 저장·종료

기존 PATCH /api/sessions/:id에 아래 필드를 추가한다.

| 필드 | 의미 |
|---|---|
| intent | save(기본값) 또는 complete |
| actualNotes | 실제 메모. 생략 시 기존 값 유지 |
| cardio | 유산소 전체 배열. 생략 시 유지, []이면 명시적 삭제 |

소유권·Origin·입력 검증 후 세션 버전을 비교한다. 세트·유산소·메모·종료 상태를 한 트랜잭션에서 저장하며 실패하면 전체 롤백한다. 종료·수정의 동시 요청은 하나만 성공하고, 오래된 버전이나 재종료 요청은 409다. 응답을 놓친 뒤에도 같은 요청으로 기록이나 종료 시각이 중복 생성되지 않는다. 409에서는 화면 입력을 유지하고 사용자가 서버 재조회를 선택한다.

‘저장하고 운동 종료’는 확인 후 status=completed, endedAt=서버 현재 시각으로 바꾼다. 별도 상태/종료 시각을 클라이언트가 주입할 수 없다. 서버 성공 응답 전에는 완료로 표시하지 않는다. 미완료 세트나 유산소를 자동 완료로 바꾸지 않으며, 부분 수행과 빈 운동도 명시적으로 종료할 수 있다. 완료 상태는 모든 목표를 달성했다는 의미가 아니다.

완료 상세는 기본 읽기 전용이다. ‘완료 기록 수정’을 눌러 세트·유산소·메모를 수정하고 저장할 수 있다. 상태와 최초 종료 시각은 유지한다. API도 소유권·버전 검사를 거쳐 완료 기록 수정을 허용한다. 운동 재개/종료 취소, 제목·날짜 변경, 감사 이력은 이번 범위에 포함하지 않는다.

과거 완료 데이터의 종료 시각이 없으면 ‘종료 시각 미기록’으로 표시한다. 과거 시각을 추정하지 않으며 수정만으로 종료 시각을 채우지 않는다.

## 재조회와 입력 보호

기록 화면은 실제 운동 날짜 내림차순으로 본인 일지 최근 100개를 보여주며 완료/진행 상태를 표시한다. 100개 초과는 안내한다. 달력·기간 검색·페이지 이동은 이후 단계다. GET /api/sessions?status=completed도 지원한다. 관리자도 다른 사용자의 일지·유산소·메모를 볼 수 없다.

유산소·메모 입력에도 기존 미저장 경고와 PWA 업데이트 방지를 적용한다. 서버 실패 시 입력은 화면에 유지한다. 영구 로컬 초안·내부 링크 이탈 복구·오프라인 전송은 C7 범위다.

## 마이그레이션과 검증

`202610280006_cardio_completion`은 WorkoutSession에 nullable endedAt와 빈 문자열 기본 actualNotes를 추가하고 CardioRecord를 만든다. 기존 실제 세트·목표·진행 상태는 수정하지 않는다. DB에도 시간·거리 범위와 완료 시 시간 필수 제약을 둔다.

통합 검증은 유산소 단위/NULL/0, 메모 보존, 트랜잭션 롤백, 동시 종료·재시도, 완료 후 수정, 이전 클라이언트의 새 필드 보존, 과거 종료 시각 NULL 유지, 관리자 포함 타인 접근 차단을 확인한다. 브라우저는 PC/320px에서 종료 저장 실패 후 입력 보존, 종료 성공, 새로고침, 기록 목록 재진입과 완료 후 수정을 검증한다.
