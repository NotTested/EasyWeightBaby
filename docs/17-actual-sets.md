# C4 실제 수행 세트

진행 중 운동 상세에서 반복 종목을 검색해 추가하고, 종목별 실제 세트를 추가·삭제·저장한다. 루틴 목표는 수행으로 자동 변환하지 않는다. 직접 추가한 종목의 목표는 NULL이며 기존 목표 스냅샷은 변경하지 않는다.

- 세트별 중량(덤벨은 개당 kg), 덤벨 수 1/2, 반복수, 수행 완료를 별도로 저장한다. 세트마다 중량을 바꿀 수 있다.
- 빈칸은 NULL, 입력한 0은 실제 0이다. 완료에는 중량·반복수가 필요하고 덤벨 종목은 덤벨 수도 필요하다. 반복 0의 완료도 명시적으로 허용한다.
- 맨몸 외부 중량은 0kg이며 체중이나 운동 강도 0을 뜻하지 않는다. 덤벨 개수는 좌우 교대 구분이 아니다. 외부 볼륨 합계는 아직 계산하지 않는다.
- 목표 세트 수와 무관하게 실제 세트 0~30개를 허용한다. 세션당 최대 40종목이며 이번 단계에서는 종목 자체 삭제·재정렬을 제공하지 않는다. 완료한 세트 삭제에는 확인한다.
- 기존 세션 종목은 사전에서 이름 변경·비활성화돼도 기록할 수 있다. 새 종목은 활성화된 공용 또는 본인 개인 반복 종목만 추가할 수 있다. 검색은 기존 사전 API의 최대 100개 결과를 사용하므로 구체적인 검색어로 좁힌다.

## 저장 계약

PATCH /api/sessions/:id에 version과 exercises 전체를 보낸다. 기존 항목은 id/exerciseId, 새 항목은 exerciseId, 각각 sets를 보낸다. 요청 필드는 엄격히 검증하고 사용자·Origin·소유권·진행 상태를 확인한다. 관리자의 타인 기록 접근도 금지한다.

한 트랜잭션에서 세션 버전을 증가시키고 세트 배열을 교체한다. 기존 종목 누락·중복·타 세션 항목은 거부한다. 동시 저장 중 하나만 성공하며 오래된 버전은 409로 돌려준다. 네트워크 응답을 놓친 뒤 재시도해도 새 종목을 중복 추가하지 않는다. 서버 재조회와 화면 입력 폐기는 사용자가 명시적으로 선택한다. 세트 ID는 교체되므로 외부 참조 키로 사용하지 않는다.

화면은 저장 확인 전 입력을 유지하고 PWA 업데이트를 막는다. 브라우저 창 닫기/새로고침에는 미저장 경고를 연결했다. 내부 링크 이동 복구·영구 로컬 초안·오프라인 전송은 C7에서 처리한다. 저장하지 않은 화면 입력은 영구 보관되지 않는다.

좌우·마지막 RIR(C5), 유산소·일지 메모·운동 종료(C6)는 아직 구현하지 않는다. C4 마이그레이션은 기존 목표 3개 필드를 nullable로 바꾸고 WorkoutSet을 추가한다. 기존 운동 데이터에 실제 수행을 추정해 채우지 않는다.
