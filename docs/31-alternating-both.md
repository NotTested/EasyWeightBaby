# 양쪽 교대 수행측 추가

사용자 확인: 12회는 좌우 각각12회, 총24회.

- 선택값 alternating_both/양쪽 교대. DB reps는 한쪽당 수를 저장한다.
- 저장·재조회·초안·읽기전용·이전비교에서 새 값을 보존하고 각/총 반복을 표시한다.
- 같은 중량·반복·RIR일 때 한 행을 사용한다. 좌우 값이 다르면 기존 왼쪽/오른쪽 행을 사용한다.
- 새 모드의 볼륨은 한쪽 부하×reps×2. 덤벨 개수를 중복 곱하지 않는다.
- 미입력과0, 기존 수행측과 원본기록은 유지한다. 새 DB CHECK 확장이 필요하다.
- NAS 반영 전 최신 암호화 백업과 새 이미지·마이그레이션·브라우저갱신을 포함한 배포 단위를 검토한다.
