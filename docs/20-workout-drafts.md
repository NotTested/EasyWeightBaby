# C7 운동 입력 초안과 재시도 보호

C6 미커밋 작업을 보존한 `feat/c6-cardio-notes-completion` 브랜치에서 진행한다. 이 문서는 C3~C6의 기기 초안 미구현 설명을 대체한다. DB 마이그레이션·의존성 추가는 없다.

## 기기 초안

운동 상세에서 종목·세트·좌우·RIR·유산소·실제 메모를 바꾸면 계정 ID와 운동 ID로 구분한 localStorage 초안에 보관한다. 저장 시각과 기준 서버 버전을 함께 보관하고, 저장 완료/실패를 서버 저장과 구분해 표시한다. 서버 목표·인증 쿠키·토큰·비밀번호·API 응답 전체는 저장하지 않는다. 원본 종목 이름/도구/실행 방식은 편집 화면 복구에 필요한 범위로만 보관한다.

- 초안 검증은 형식·소유자·운동 ID·용량·배열 크기를 확인하며 미완성 입력은 허용한다. 예를 들어 종류가 빈 유산소 행이나 미완료 세트를 복구할 수 있다. 서버 저장 검증은 기존 C4~C6 규칙을 유지한다.
- 다시 열면 자동 적용하지 않고 ‘기기 초안 복구’ 또는 삭제를 선택한다. 선택 전 편집을 잠근다. 운동 시작 화면에서 본인 계정의 보관된 운동 초안 링크를 볼 수 있다.
- 기준 버전/상태가 현재 서버와 다르면 복구는 확인·수정용으로 허용하되 서버 저장을 막는다. 최근 확인한 서버 기록과 비교하고 현재 입력을 텍스트로 내려받을 수 있다. 자동 병합이나 새 버전으로의 자동 재적용은 하지 않는다.
- 서버 저장 성공을 확인한 뒤 이 탭이 보관한 초안을 지운다. 다른 탭이 바꾼 초안은 저장 성공만으로 삭제하지 않는다.
- 다른 탭의 변경을 감지하면 이 탭의 자동 보관을 중지하고 텍스트 보관을 안내한다. 기기 초안은 한 운동당 하나이며 협업 편집이나 기기간 동기화 기능이 아니다. 서버 동시 수정은 기존 버전 검사로 막는다.
- 브라우저 저장 공간 거부·용량 부족·손상된 초안은 성공으로 표시하지 않는다. 손상된 초안은 명시적으로 초기화할 수 있다. 텍스트 내려받기를 대안으로 제공한다.

## 이탈·연결·세션

미저장 입력이나 전송 중 요청이 있으면 창 닫기/새로고침 경고를 연결하고 pagehide/화면 이탈 때 보관을 시도한다. 내부 링크 클릭에는 이동 확인을 제공한다. 브라우저 뒤로/앞으로 이동은 차단하지 않고 기기 초안 복구를 사용한다. 브라우저 강제 종료·전원 차단·저장 공간 장애에서는 모든 입력 보존을 보장할 수 없으므로 보관 상태를 확인해야 한다.

오프라인에서는 현재 열려 있는 운동 입력을 계속 보관하되 서버 저장·종료는 보내지 않는다. 연결이 복구돼도 자동 전송하지 않고 사용자가 저장을 선택한다. 일반 네트워크 실패나 401에는 입력을 유지한다. 세션 만료는 재로그인 안내를 표시하고, 재로그인 후 같은 계정의 운동을 열어 복구할 수 있다. 409에는 서버 기록을 다시 확인하고 자동 덮어쓰기를 막는다. 중복 클릭은 전송 중 잠금으로 차단한다.

명시적 로그아웃에는 초안 삭제를 알리고 해당 계정의 운동 초안과 미확인 시작 요청을 정리한다. 다른 계정의 초안·다른 사이트 저장 키는 지우지 않는다. storage 이벤트·BroadcastChannel과 로그아웃 표식으로 같은 계정의 다른 탭을 잠가 초안을 다시 쓰지 않도록 한다. 정리 실패 시 로그인 화면에 실제 실패를 안내한다. 세션이 단순 만료된 경우에는 복구를 위해 초안을 지우지 않는다.

초안은 브라우저의 사이트 저장소에 남는 개인 데이터이며 암호화 보관함이 아니다. 정상 저장·명시적 삭제·로그아웃 전까지 남고 자동 만료는 없다. 브라우저의 사이트 데이터 삭제나 시크릿 창 종료로 사라질 수 있다.

## 운동 시작 요청

운동 시작 POST 전에 계정별로 요청 키와 검증된 본문을 보관한다. 응답을 놓치고 새로고침해도 ‘동일 시작 요청 다시 확인’을 누르면 동일 키/본문으로 서버의 C3 멱등성 처리를 사용한다. 결과가 미확인인 동안 새 시작 입력을 잠그고, 새 운동을 원하면 진행 중 목록을 확인한 뒤 보관된 요청을 명시적으로 삭제한다. 서버가 거부를 확인한 400/403/404/415 요청은 정리한다. 형식이 손상된 요청은 목록 확인 후 초기화를 제공한다.

시작 요청을 기기에 보관할 수 없으면 전송 전에 중단한다. 오프라인에서 새 운동을 만들거나 보관된 시작 요청을 자동 재전송하지 않는다. 요청을 제출하기 전 제목·루틴 선택 자체를 영구 초안으로 보관하는 기능은 포함하지 않는다.

## 범위와 검증

PWA 캐시에는 여전히 공용 오프라인 문서만 둔다. 인증 HTML·API를 캐시하지 않으므로 오프라인에서 새로고침하면 오프라인 안내가 나오며, 온라인으로 돌아와 운동 상세를 열 때 초안을 복구한다. 완전한 오프라인 앱 시작·양방향 동기화·자동 전송 대기열, 종목 사전/루틴 편집기의 영구 초안은 범위 밖이다. 미저장 운동 입력이 있으면 기존 PWA 업데이트 보호도 유지한다.

단위 검증은 계정/운동/형식 검증과 미완성 입력 보존을 다룬다. Chromium PC/320px 검증은 새로고침 복구·이동 취소/승인·오프라인 입력 및 명시적 재시도·저장 후 초안 정리, 서버 버전 변경·401·탭 간 초안 충돌·로그아웃 계정별 정리·다른 탭 잠금·저장 공간 실패를 다룬다. 시작 POST를 실제 서버에서 처리한 뒤 브라우저 응답을 끊고 새로고침/재시도해도 운동이 한 번만 생성되는지 확인한다.
